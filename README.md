# CyberSecurityChatbotPart2
---
## Introduction
CyberSecurityChatbotPart2 is a Cyber Security Awareness Chatbot developed using C# and Windows Presentation Foundation (WPF). This version builds on Part 1 by introducing a graphical user interface (GUI), improved user interaction, and additional chatbot functionality.

The chatbot is designed to educate users about common cybersecurity threats and online safety practices through an interactive and user-friendly experience.

---

### Personalised User Experience

- Prompts the user for their name.
- Greets users personally throughout the conversation.
- Creates a more engaging interaction.
  
### Voice Greeting

- Plays a welcome audio message when the application starts.
- Enhances user engagement.


### Cybersecurity Topic Selection

Users can choose from the following cybersecurity topics:

- Phishing
- Password Security
- Malware
- Safe Links
- Firewall Protection
- VPN Security

### Interactive Chat Interface

- Allows users to chat with the chatbot.
- Displays both user and chatbot messages.
- Maintains conversation history.

### Sentiment Detection

The chatbot recognises basic user emotions and responds appropriately.

Examples include:

- Worried
- Concerned
- Curious
- Frustrated

This makes interactions feel more personal and realistic.

### Keyword Recognition

The chatbot can identify cybersecurity-related keywords and provide relevant information.

### Error Handling

- Handles invalid input.
- Prevents crashes from unexpected user actions.
- Provides clear feedback to users.

## Cybersecurity Topics Covered

### Phishing

The chatbot provides advice on:

- Identifying suspicious emails
- Preventing phishing attacks
- Protecting personal information

### Password Security

The chatbot explains:

- Strong password creation
- Password management
- Multi-factor authentication

### Malware

Users learn about:

- Common malware threats
- Safe downloading practices
- Device protection methods

### Safe Links

The chatbot provides information on:

- Recognising suspicious links
- URL verification
- Safe browsing habits

### Firewall Protection

Users learn about:

- Network protection
- Firewall functionality
- Cybersecurity best practices

### VPN Security

The chatbot explains:

- Online privacy
- Secure internet connections
- Public Wi-Fi safety

## How to Run the Application

### Prerequisites

Before running the application, ensure you have:

- Visual Studio 2022 or later
- .NET Framework installed
- Windows operating system

### Installation

1. Clone the repository.
2. Open the solution in Visual Studio.
3. Build the project.
4. Run the application.
5. Enter your name.
6. Select a cybersecurity topic.
7. Begin interacting with the chatbot.
